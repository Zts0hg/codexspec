## P-2026-0829-0035hy-4: Cross-round state must retain unresolved inputs as well as new outputs

- claim: A retry coordinator must carry forward every unresolved input obligation until an independent worker records a terminal disposition, not only obligations newly emitted by the current round.
- type: pitfall
- scope/when: implementing caller-owned state handoff for retry, repair, approval, or verification loops
- root-cause: rebuilding the next-round handoff solely from the current round's outgoing records silently drops an older obligation when the current worker reports it as unresolved input without emitting a duplicate output record.
